A simple file serving web server similar to the VS code plugin "live server"

## Acquisition
[Download](https://github.com/abelvandenbussche/file_server/releases/latest/download/live.exe) the executable from [latest](https://github.com/abelvandenbussche/file_server/releases/latest) release

## Use
live \[path]\
  path = path to main html file eg. index.html
